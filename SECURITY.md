# Security policy

## Important limitation

Plasma Visual Screensaver is a decorative overlay for an unlocked session. It
does not authenticate users, secure applications, or replace KDE Plasma's lock
screen. Anyone who dismisses it can use the session.

Do not report the absence of password authentication as a vulnerability; it is
an explicit product boundary. Use Plasma's lock screen when access control is
required.

## Reporting a vulnerability

For vulnerabilities within the application's stated boundary, use GitHub's
private vulnerability reporting feature if it is enabled for the repository.
Otherwise contact the maintainer at `stantonmatthewj@gmail.com` before opening
a public issue. Include affected versions, reproduction steps, and impact.
